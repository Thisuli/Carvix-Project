# Carvix – Vehicle Service Booking & Management System

Carvix is a MERN-stack web application developed for managing vehicle service bookings.

## Features

### Customer
- View available vehicle services
- Book a service appointment
- Receive a booking reference
- Track booking status

### Administrator
- Secure administrator login
- View all bookings
- Approve, reject, complete, and delete bookings
- Manage service categories
- View customer information and booking history
- View dashboard statistics
- Change administrator password

## Technologies Used

### Frontend
- React
- Vite
- CSS
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- bcryptjs
